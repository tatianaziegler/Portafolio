# ROH and Inbreeding Analysis (FROH)

This project evaluates genomic inbreeding using Runs of Homozygosity (ROH).

## Populations
- POP1
- POP2

## Methods
- ROH detection using detectRUNS
- Classification by length (1–2 Mb, 2–4 Mb, 4–8 Mb, >8 Mb)
- FROH estimation per individual
- Comparative population analysis

## Outputs
- FROH distribution
- ROH length classes
- Comparative plots

## Interpretation
Long ROHs indicate recent inbreeding, while shorter ROHs reflect ancient demographic events.

## Tools
R, detectRUNS, dplyr, ggplot2
