# FST Analysis – Selection Signatures

This project calculates genetic differentiation (FST) between two goat populations (pop1, pop2) using SNP data.

## Methods
- VCF processing in R
- SNP filtering (common markers)
- FST estimation using hierfstat

## Output
- Per-locus FST values
- Distribution plots
- Manhattan-style visualization

## Tools
R, vcfR, adegenet, hierfstat, ggplot2
