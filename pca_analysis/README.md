# Population Structure Analysis (PCA)

This project analyzes genetic structure between two populations (POP1 and POP2) using SNP data.

## Objective
To explore genetic diversity and population clustering using Principal Component Analysis (PCA).

## Methods
- SNP data processing using PLINK
- Filtering of non-informative markers
- PCA using prcomp in R

## Outputs
- 2D PCA plot
- 3D interactive PCA visualization
- Variance explained by principal components

## Interpretation
Separation between populations indicates genetic differentiation and structure.

## Tools
R, PLINK, ggplot2, plotly
